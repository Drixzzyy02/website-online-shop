# WebKu - Website Online Shop

Website online shop berbasis PHP native dengan fitur manajemen produk, keranjang belanja, checkout, dan dashboard admin.

## Fitur
- Login & Logout
- Dashboard admin
- CRUD produk
- Kategori & brand produk
- Keranjang belanja
- Checkout produk
- Riwayat transaksi
- Konfirmasi pesanan
- Manajemen stok produk
- Responsive design

## Teknologi
- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
